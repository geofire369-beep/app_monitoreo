# app_monitoreo

Aplicación desarrollada para **GEOPÓNICA S.A.P.I. de C.V.** enfocada en el registro, consulta y seguimiento de información de monitoreo, con acceso a módulos administrativos y generación de reportes.

> Plataformas objetivo: **Android** y **Web**.

---

## ✨ Funcionalidades principales

- Captura y registro de información de monitoreo.
- Consulta de registros y visualización por módulos.
- Módulo administrativo para gestión y revisión de información.
- Generación de reportes (según configuración del proyecto).
- Soporte para ejecución en **Android** y **Web**.

---

## 🧰 Tecnologías

- **Flutter** (Dart)
- **Firebase** (servicios según implementación: Auth / Firestore / Storage, etc.)
- Estructura modular para facilitar mantenimiento y evolución del sistema.

---

## 📦 Requisitos

- **Flutter SDK**
- Navegador (para Web)
- Android Studio (opcional) o un dispositivo/emulador Android
